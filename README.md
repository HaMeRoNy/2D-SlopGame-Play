# ZooCartel — веб-версия

Играть: https://hamerony.github.io/2D-SlopGame-Play/

Управление: WASD — ходьба, Shift — бег, мышь — взгляд, колесо — зум, F — фонарь, 1 / 2 / 3 — пистолет / лук / убрать, ЛКМ — выстрел, R — перезарядка, F1 — отладка (перенос по карте, жители: сколько, подписи, «шум здесь», «стража ↔ бандит», громкость), F2 — внешность.

В городе живут горожане, стража и бандиты: ходят по распорядку, бегут от выстрелов, стража окликает и стреляет, бандиты отвечают.

Сборка из закрытого репозитория игры (Godot 4.7.2, Web без потоков). Только одиночная игра — сеть в версии для компьютера.
